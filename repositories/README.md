# Repositórios

Cada projeto de software deve residir em um subdiretório próprio. Documentos globais e decisões transversais ficam em `../docs/`.

Repositórios planejados:

- `app-android/` — diagnóstico local e captura futura de intenção no Android.

Esta pasta-mãe não pressupõe que todos os subdiretórios tenham um remoto Git configurado. A criação do repositório Git pode ser feita quando o usuário escolher onde hospedá-lo; nenhum remoto foi inventado.
